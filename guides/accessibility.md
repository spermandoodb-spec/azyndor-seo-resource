# Accessibility Fundamentals

Accessible video experiences should provide synchronized captions, keyboard-operable controls, visible focus states, sufficient contrast, readable text, and responsive mobile layouts.

Test player controls with a keyboard, check captions for timing and accuracy, and verify that information is not communicated through color alone. Automated testing is useful, but manual checks remain important.
