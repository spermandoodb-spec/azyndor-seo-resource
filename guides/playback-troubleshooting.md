# Playback Troubleshooting

When a video does not play, begin with safe, reversible checks:

1. Check the network connection.
2. Reload the page once.
3. Update the browser.
4. Close unnecessary tabs.
5. Temporarily test with extensions disabled.
6. Try another supported device or browser.

For sound problems, check the device output, tab mute state, and player volume. For buffering, compare another network or reduce playback quality if available. Do not install unknown codecs or executable updates from pop-ups.

When contacting support, share non-sensitive diagnostic details such as browser version and error text. Never share passwords or authentication codes.
