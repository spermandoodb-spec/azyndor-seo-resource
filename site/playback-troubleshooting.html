Online Video Playback Troubleshooting

Playback issues can originate from network conditions, browser settings, device limitations, or a service interruption.

Safe first steps

  1. Check whether other websites load normally.
  2. Reload the page once.
  3. Update the browser to a supported version.
  4. Close unnecessary tabs and applications.
  5. Temporarily test with extensions disabled.
  6. Try another supported browser or device.

Common symptoms

Buffering: Compare another network or lower playback quality if available.

No sound: Check device output, tab mute state, and player volume.

Black screen: Check browser support and settings. Do not install unknown codecs or executable updates from pop-ups.

When contacting support, include browser version, device type, error text, and steps tried. Never send passwords or authentication codes.
